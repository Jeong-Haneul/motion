# 자세 라벨링 체계 (PoseCode v0.1)

> **주 체계는 `posture-axes.md` (정성 축, v0.2)** 이다. 이 문서는 같은 자세를 관절 좌표에서 수치 임계값으로 자동 라벨링하는 **선택적 측정 구현**(v0.1)이다.

목표: **라벨 몇 개만 읽어도 자세가 상당히 특정되는** 체계. 라벨 수(주석 비용)와 표현력(특정 능력)의 절충을 구조로 푼다.
동작은 별도 체계가 아니라 **자세 라벨의 시퀀스 + 전이 라벨**이다.

기계가독 스키마: `posture_labels.schema.json` · 구현: `../labeler.py` · 예시 자세: `../library.py`

---

## 1. 절충을 푸는 다섯 가지 설계 원칙

| # | 원칙 | 효과 |
|---|---|---|
| 1 | **축을 직교하게 쪼갠다 (인수분해)** | 표현 가능한 자세 수 = 각 축 수준 수의 **곱**, 주석 비용 = **합**. 축 15개 × 평균 3~4수준이면 비용은 수십 번의 선택이고 조합은 수백만 |
| 2 | **축당 수준은 3~7개** | 연속값은 측정 가능한 임계값으로 구간화(순서형). 진짜 범주만 명목형 |
| 3 | **모든 축에 `*`(미지정) 허용** | 라벨은 부분 제약이다. 거칠게도, 촘촘하게도 쓸 수 있다 |
| 4 | **좌우는 역할 기준, 편향은 `CHI` 한 축** | 거울상은 `CHI`만 다르다 → 라벨 공간이 절반. (구현에서 검증: 거울 변환 후 `CHI` 외 차이 0) |
| 5 | **층을 나눈다**: 측정 층(관절 좌표에서 계산) / 지각 층(사람이 평가) | 측정 층은 자동·재현 가능, 지각 층은 평정자 일치도로 관리 |

## 2. 축 목록

### CORE — 자세의 뼈대 (9축, 19.8 bit ≈ 94만 조합)
| 축 | 의미 | 수준 |
|---|---|---|
| `BASE` | **대분류** (지지 방식) | `ST` 서기 · `SI` 앉기 · `KN` 무릎꿇기 · `SQ` 쪼그려 · `LY` 눕기 · `SU` 손발 짚기 · `AI` 공중 |
| `SUP` | 하체 하중 | `EV` 양발 균등 · `BI` 양발 편중 · `ONE` 한 발 · `NO` 없음 |
| `SPR` | 좌우 벌어짐 (고관절 폭 대비; 서기=발목, 그 외=무릎) | `1` 붙임 <0.9 · `2` 좁음 <1.4 · `3` 보통 <2.2 · `4` 넓음 <3.2 · `5` 매우 넓음 |
| `FLA` | 무릎 굽힘, 더 굽힌 다리 | `EXT` <25° · `SLI` <60° · `RGT` <115° · `DEP` ≥115° |
| `REL` | 다리 관계 | `PL` 두 발 바닥 · `AX` 발목 교차 · `KK` 무릎 겹침 · `F4` 발을 반대 무릎에 · `RL/RM/RH` 한 발 들림 낮음/허리/높음 |
| `TRK` | 상체 앞뒤 기울기 | `RC` <-8° · `UP` · `LS` 12–30 · `LN` 30–60 · `FD` >60 |
| `ARH` | 손 높이 (골반=0, 정수리=1) | `LO` <0.25 · `MI` <0.65 · `HI` <1.0 · `OV` 머리 위 |
| `ARR` | 팔 뻗음 (몸통 선분에서 손목까지 / 팔 길이) | `TU` <0.45 · `MD` <0.8 · `EX` |
| `FAC` | 기준 방향 대비 몸 방향 | `FR` <30° · `OB` <70 · `SD` <110 · `BK` |

### STANDARD — 해상도 보강 (7축, +13.1 bit)
`STG` 발 위치 비대칭(나란함/앞뒤/한쪽으로 기움) · `FLB` 덜 굽힌 다리 · `CHI` 좌우 편향(L/R/S) · `SPN` 척추 곡률 · `TWB` 상체 비틀림·옆굽힘 · `HED` 머리(중립/기울임/숙임/들음/돌림) · `HCT` 손 접촉(없음/맞닿음/몸/바닥·물체)

### STYLE — 지각 층 (사람이 평가, 7.0 bit)
| 축 | 의미 | 수준 |
|---|---|---|
| **`GND` 남녀** | 자세·동작이 **여성적으로 읽히는지 ↔ 남성적으로 읽히는지** | `-2` 여성적 … `+2` 남성적 |
| **`AGE` 노소** | **어리게 ↔ 노년으로 읽히는지** | `-2` 아동 · `-1` 젊고 활기참 · `0` 성인 중립 · `+1` 중년 이상 · `+2` 고령 |
| `OPN` 개방–폐쇄 | 몸이 열려 있는가. 기하 지표(좌우 확장 비율)로 사전 제안, 사람이 확정 | `-2` … `+2` |

확장 팩(필요할 때만): `TEN` 긴장–이완, `FRM` 격식.

### 도메인 팩 — 필요한 분야만 (예: `STRIKE`)
`PTH` 타격 경로(`LN` 직선/`MX`/`AR` 호) · `LED` 타격면(`SO` 발바닥 `IN` 발등 `BL` 발날 …). 태권도처럼 한 순간 자세로는 갈리지 않는 동작에만 붙인다(7절).

## 3. 남녀·노소 축 정의 규칙

- **연기자의 성별·나이가 아니라, 그 자세·동작이 풍기는 인상**이다. 같은 자세도 문화권에 따라 읽히는 방식이 다르므로 **문화권 태그**(`KR`, `US` …)를 같이 기록한다.
- **체형은 라벨이 아니다.** 신장·비율·허리/엉덩이 비는 별도 파라미터로 둔다. 연구에서 범주 판단은 체형이 좌우하고 움직임은 지각된 성별을 통해 영향을 준다고 보고되어 있어([Psychological Science](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.2005.01633.x/)), 둘을 섞으면 축이 오염된다.
- **평정 규칙**: 평정자 5명 이상, 5점 척도 + "판단 불가" 허용. 단일 값이 아니라 **평정 분포(평균·분산)** 를 저장한다. 평정자 일치도(κ 또는 ICC)가 낮은 하위 범주는 축에서 제외하거나 합친다.
- **기하 상관(사전 제안용, 정의 아님)**
  - 남녀: 앉기에서는 남성은 열린 자세, 여성은 닫힌 자세가 더 자주 관찰되고 열린 자세는 더 남성적으로 평가됨([UNH 관찰 연구](https://scholars.unh.edu/perspectives/vol2/iss1/16), [자세와 성별 인상 연구](https://www.sbp-journal.com/index.php/sbp/article/view/1003)). 걷기에서는 골반 흔들림이 여성적, 어깨 흔들림이 남성적으로 읽힘. → `SPR`, `OPN`, `STG:SL`, `HCT:BD`와 보행 동역학.
  - 노소: 고령일수록 느리고, 보폭이 짧고, 지지면이 넓고, 팔 흔들림이 작음([PLoS ONE 2015](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4549059/)). → 전이 축 `TMP`(속도), `SPR`, `ARR`. 자세 자체(상체 굴곡 등)의 연령 효과는 이번 조사에서 직접 확인하지 못함.
- 이 상관은 **정적 자세에서는 약하다**. 정적 자세의 `GND`/`AGE`는 대부분 사람이 평정해야 한다.

## 4. 라벨 레코드

```json
{ "id": "pose_0007", "ref": [0,0,1], "culture": "KR",
  "CORE": {"BASE":"ST","SUP":"EV","SPR":"2","FLA":"EXT","REL":"PL","TRK":"UP","ARH":"OV","ARR":"EX","FAC":"FR"},
  "STANDARD": {"CHI":"S","HED":"RS"},
  "STYLE": {"GND": {"mean":0.1,"n":7}, "AGE": {"mean":-0.8,"n":7}, "OPN":"+1"} }
```
문자열 형태: `BASE:ST|SUP:EV|SPR:2|FLA:EXT|REL:PL|TRK:UP|ARH:OV|ARR:EX|FAC:FR`

## 5. 라벨 예시 (실제 라벨러 출력)

| 자세 | CORE 코드 | OPN 제안 |
|---|---|---|
| **만세** (선 채 두 팔 위로) | `BASE:ST\|SUP:EV\|SPR:2\|FLA:EXT\|REL:PL\|TRK:UP\|ARH:OV\|ARR:EX\|FAC:FR` | +1 |
| 차렷에 가까운 서기 | `BASE:ST\|SUP:EV\|SPR:2\|FLA:EXT\|REL:PL\|TRK:UP\|ARH:LO\|ARR:TU\|FAC:FR` | 0 |
| 앉기: 무릎 모음 + 다리 한쪽으로 기움 + 손은 무릎 위 | `BASE:SI\|SUP:EV\|SPR:1\|FLA:RGT\|REL:PL\|TRK:UP\|ARH:LO\|ARR:TU\|FAC:FR` + `STG:SL\|CHI:L\|HCT:PA` | -1 |
| 앉기: 다리 벌림 + 뒤로 젖힘 | `BASE:SI\|SUP:EV\|SPR:4\|FLA:RGT\|REL:PL\|TRK:RC\|ARH:LO\|ARR:MD\|FAC:FR` | +2 |
| 앉기: 무릎 폭 중립 | `BASE:SI\|SUP:EV\|SPR:2\|FLA:RGT\|REL:PL\|TRK:UP\|ARH:LO\|ARR:MD\|FAC:FR` | 0 |
| 앉기: 무릎 위에 무릎 | `BASE:SI\|SUP:EV\|SPR:1\|FLA:RGT\|REL:KK\|TRK:UP\|ARH:LO\|ARR:MD\|FAC:FR` | -2 |

- 앉기 4종은 CORE만으로 서로 2~3개 축씩 달라 모두 구분된다.
- "단정하게 모아 앉기"는 CORE로는 `SPR:1`과 `ARR:TU`로 중립 앉기와 갈리고, `STG:SL`(다리 기움)이 STANDARD에서 이를 확정한다. 여기에 사람이 `GND`를 평정한다. **`GND`는 아직 아무도 평정하지 않았으므로 위 표에서 비어 있다.**

## 6. 동작 = 자세 시퀀스 + 전이 라벨

동작 라벨: `[자세 코드 @구간] → (전이) → [자세 코드 @구간] → …`
- **핵심 자세**: 동작을 정의하는 축 `BASE·SUP·REL·FAC·FLA`가 바뀔 때 새 구간. 나머지 축은 구간 최빈값으로 채운다(흔들리는 축으로 분절하면 구간이 14개까지 쪼개짐).
- **전이 축(최소)**: `TMP` 템포(느림/보통/빠름/폭발), `DUR` 길이, 필요하면 도메인 팩.

오른발 돌려차기(손 작성 샘플, 코어 축만)의 자동 시퀀스 (요약, 인접 구간 일부 병합):
```
0.00–0.15  ST|BI |REL:PL|FAC:OB     준비 서기, 몸이 사선
0.17–0.33  ST|ONE|REL:RL|FAC:FR|FLA:RGT  한 발 들기 시작
0.35–0.42  ST|ONE|REL:RM|FAC:OB     무릎 접어 들기(chamber)
0.43–0.52  ST|ONE|REL:RH|FAC:SD|FLA:EXT  높게 뻗음, 몸이 옆을 향함  ← 충격
0.53–0.65  ST|ONE|REL:RM|…          회수
0.75–0.83  ST|ONE|REL:PL|FAC:FR     착지
```
결함 돌려차기(힙 회전 없이 다리만 휘두름)는 같은 방식으로 `FAC`가 `FR/OB`에 머물러 `SD`에 도달하지 못하고 `FLA`도 `SLI`에 머문다 → **결함이 라벨로 드러난다.**

**한계(중요)**: 돌려차기와 옆차기는 충격 순간 자세 라벨이 같다(`ST|ONE|SPR:5|REL:RH|FAC:SD|FLA:EXT`). 한 순간의 자세만으로는 구분되지 않으므로 도메인 팩 `PTH`(호/직선)가 필요하다. 샘플에서 `strike_vs_limb`(타격 속도와 다리 축의 각)가 돌려차기 70°(`AR`), 옆차기 22°(`LN`)로 갈렸다. `LED`(타격면)는 손으로 만든 샘플의 발 방향과 충격 시점 검출 방식 때문에 아직 신뢰할 수 없다.

## 7. 라벨 수 대 표현력: 실제로 정하는 절차

비용과 표현력을 각각 수치로 두고 축을 고른다.

- **비용** `C = Σ log2(수준 수)` bit, 그리고 축별 평정자 일치도 κ. (현재: CORE 19.8 · +STANDARD 13.1 · +STYLE 7.0)
- **표현력(특정 능력)**
  1. *라벨 내 분산*: 같은 라벨을 가진 자세들끼리의 평균 관절 위치 오차(키로 정규화). 작을수록 "특정된다".
  2. *복원*: 라벨만 주고 자세를 생성/검색했을 때 정답 자세와의 오차, top-k 회수율.
  3. *변별*: 라벨 쌍 사이 거리 대비 라벨 내 거리.
- **선택**: 정보 이득 / bit 가 큰 축부터 전진 선택 → 다른 축으로 설명되는 축(조건부 상호정보 ≈ 0)은 후진 제거 → κ < 0.6 인 축은 합치거나 제외 → 비용–오차 곡선의 꺾이는 점에서 멈춘다.
- **층 구조로 선택을 단순화**: 거친 검색·생성 조건은 CORE만, 정밀 지정은 +STANDARD, 인상 제어는 +STYLE.

## 8. 이번에 확인한 것 / 확인하지 못한 것

확인함 (손으로 만든 8개 자세·4개 차기 동작에서)
- 앉기 4종 CORE 코드가 모두 다름. 거울 변환 후 라벨 차이는 `CHI`뿐 (자세 4종, 시퀀스 3종).
- 결함 돌려차기와 정상 돌려차기가 `FAC` 경로로 갈림.
- 돌려차기와 옆차기는 자세만으로 안 갈리고 `PTH`로 갈림.
- 만세는 `ARH:OV|ARR:EX`로 표현됨.

확인하지 못함
- **실제 사람 데이터에서의 동작**. 샘플은 제가 직접 작성했고 라벨러와 임계값도 제가 정했으므로 순환 위험이 있다. 임계값은 전부 임시값이다.
- `TRK`, `ARH`, `ARR`, `HED`가 샘플에서 거의 변하지 않아 이 축들의 변별력은 검증되지 않았다.
- `KN`, `SQ`, `LY`, `SU`, `AI`(대분류 중 서기·앉기 외)는 규칙만 있고 테스트 자세가 없다.
- `GND`, `AGE`의 평정자 일치도, 문화권 차이.
- 노소 축의 정적 자세 상관.

## 9. 다음 단계

1. 실제 모션캡처 코퍼스(AMASS 등)에 라벨러를 적용해 임계값을 데이터로 보정 (현재 이 환경에서는 arXiv·데이터 호스트 접근이 막혀 있음).
2. `GND`·`AGE` 평정 파일럿: 자세 100개 × 평정자 7명, 문화권 2개. κ와 평정 분산으로 축 정의를 다듬는다.
3. 7절의 절차로 축별 정보 이득과 κ를 측정해 Pareto 곡선을 그리고 STANDARD 축 수를 확정.
4. `TMP` 등 전이 축과 도메인 팩 정의.
