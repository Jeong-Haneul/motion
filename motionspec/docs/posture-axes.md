# 자세 축 체계 v0.2 (정성)

수치 임계값 없이, **말로 된 대립쌍과 범주**로 자세를 특정한다. 주석자는 자세를 보고 각 축의 질문에 답한다.
각 축에는 **좌우·상하·전후 반전**을 했을 때 값이 어떻게 변하는지가 함께 정의되어 있다.

정의·스키마: `../axes.py`, `posture_axes.schema.json`

## 1. 설계 원칙

1. **축 = 질문 하나.** 값은 말로 된 3~8개 이하의 선택지이고, 중립값과 `*`(모름·미지정)이 있다.
2. **비대칭 축**을 따로 둔다. 좌우·상하·전후처럼 "뒤집으면 값이 바뀌는" 성질은 이 축들에만 담고, 나머지 축은 뒤집어도 값이 같다.
   → 거울상 자세는 비대칭 축 값만 바꾸면 되므로 라벨 수가 줄고, 데이터 증강도 정확해진다.
3. **부위 축은 역할 기준.** "더 활동적인 쪽"을 기술하고, 그쪽이 왼쪽인지 오른쪽인지는 `좌우` 축 하나가 말한다.
4. **값마다 대표 자세(anchor)** 를 둔다. 애매하면 가장 닮은 대표 자세를 고른다. 수치를 재지 않는다.
5. **층**: 필수 6축 → 표준 +8축 → 스타일(사람이 평가) +2축. 필요한 만큼만 라벨링한다.

## 2. 축 목록

### 범주 축
| 축 | 질문 | 값 |
|---|---|---|
| **대분류** | 몸을 무엇이 어떻게 받치나? | 서기 · 앉기 · 눕기 · 꿇기 · 쪼그리기 · 기대기 · 짚기 · 공중 |
| 체중 지지 | 체중이 받쳐지는 모양은? | 균등 · 한쪽 치우침 · 한 점 · 없음 |

### 비대칭 축 (뒤집으면 값이 바뀜)
| 축 | 질문 | 값 | 반전 시 |
|---|---|---|---|
| **좌우** | 좌우가 같은가, 어느 쪽이 우세한가? | 대칭 · 왼 우세 · 오른 우세 | **좌우 반전**: 왼↔오른 |
| **상하** | 머리가 위인가 아래인가? | 정립 · 수평 · 도립 | **상하 반전**: 정립↔도립 |
| **전후 방향** | 몸이 기준 방향을 어느 쪽으로 향하나? | 정면 · 사선 · 옆 · 등 | **전후 반전**: 정면↔등 |
| 상·하체 엇갈림 | 상체와 하체가 같은 쪽을 향하나? | 일치 · 엇갈림 | 불변 |

### 형태 축 (극성)
| 축 | 질문 | 값 |
|---|---|---|
| 열림–닫힘 | 몸이 모여 있나, 펼쳐져 있나? | 닫힘 · 중립 · 열림 |
| 상체 모양 | 상체는 어떤 모양인가? | 곧음 · 젖힘 · 숙임 · 말림 · 옆굽힘 |
| 다리 모양 | 무릎은 얼마나 접혔나? | 폄 · 약간 굽힘 · 직각 정도 · 깊이 접음 |
| 다리 간격 | 두 다리는 얼마나 떨어져 있나? | 붙임 · 보통 · 벌림 |
| 다리 관계 | 두 다리는 서로 어떤 관계인가? | 나란함 · 교차·겹침 · 한쪽 들림 |
| 팔 모양 | 팔은 어디로 향하나? | 내림 · 모음 · 앞으로 뻗음 · 옆으로 뻗음 · 위로 뻗음 · 뒤로 · **굽혀 올림**(팔꿈치를 굽혀 손을 어깨~머리 높이로: 손 흔들기, 경례) |
| 머리·시선 | 머리와 시선은 어디를 향하나? | 정면 · 위 · 아래 · 옆 · 기울임 |

### 얼굴·손 축 (확장)
| 축 | 질문 | 값 |
|---|---|---|
| 손 모양 | 손은 어떤 모양인가? | 자연 · 펴짐 · 주먹 · 가리킴 · 기호 |
| 눈 | 눈은 어떤 상태인가? | 뜸 · 감음 · **한쪽 감음**(윙크) · 가늘게 |
| 입 | 입은 어떤 모양인가? | 다묾 · 미소 · 벌림 · 오므림 |

### 관계 축
| 접촉 | 몸이 무엇과 닿아 있나? | 없음 · 자기 접촉 · 물체·바닥 · 타인 |

### 스타일 축 (사람이 평가하는 지각 라벨)
| 축 | 질문 | 값 |
|---|---|---|
| **남녀** | 이 자세·동작이 어느 쪽으로 읽히나? (인물의 성별이 아님) | 여성적 · 약간 여성적 · 중립 · 약간 남성적 · 남성적 |
| **노소** | 이 자세·동작이 몇 살쯤으로 읽히나? (실제 나이가 아님) | 아이 · 젊음 · 성인 · 중년 이상 · 노년 |
| 긴장–이완 (선택) | 몸에 힘이 들어가 있나? | 이완 · 보통 · 긴장 |

스타일 축은 평정자 여럿의 분포로 저장하고 문화권 태그를 붙인다. 체형은 라벨이 아니라 별도 파라미터이다.

### 부위별 좌우 표기 (`@왼` `@오른` `@양쪽`)
`좌우` 축은 몸 전체의 우세 쪽만 말한다. 오른손으로 흔들면서 왼눈으로 윙크하는 것처럼 **부위마다 쪽이 다르면** 값 뒤에 쪽을 붙인다.
쪽 표기를 받는 축은 팔 모양 · 손 모양 · 눈 · 다리 관계이다. 좌우 반전 때 `@왼`↔`@오른`이 함께 바뀐다.

## 3. 반전 규칙

| 연산 | 값이 바뀌는 축 | 비고 |
|---|---|---|
| **좌우 반전** | `좌우` (왼 우세↔오른 우세), 그리고 모든 `@왼`↔`@오른` | 나머지는 불변. 대칭 자세는 라벨이 그대로 |
| **상하 반전** | `상하`(정립↔도립), `대분류`(서기↔짚기), `팔 모양`(위로 뻗음↔내림), `머리·시선`(위↔아래) | 다른 축(상체 모양 등)은 재해석이 필요할 수 있다 |
| **전후 반전** | `전후 방향`(정면↔등), `상체 모양`(젖힘↔숙임) | |

두 번 뒤집으면 원래 라벨로 돌아온다(코드에서 모든 예시로 검증).

## 4. 예시

| 자세 | 라벨 |
|---|---|
| **만세** | 서기 / 균등 / 대칭 / 정립 / 정면 / 일치 / **열림** / 곧음 / 폄 / 보통 / 나란함 / **위로 뻗음** / **시선 위** / 접촉 없음 |
| 단정하게 모아 앉기 | 앉기 / 균등 / **왼 우세** / 정립 / 정면 / 일치 / **닫힘** / 곧음 / 직각 정도 / **붙임** / 나란함 / **모음** / 기울임 / 자기 접촉 · 남녀 **여성적**(평정) |
| 다리 벌려 젖혀 앉기 | 앉기 / 균등 / 대칭 / 정립 / 정면 / 일치 / **열림** / **젖힘** / 직각 정도 / **벌림** / 나란함 / 내림 / 정면 / 자기 접촉 · 남녀 **남성적**(평정) |
| 다리 꼬고 앉기 | 앉기 / 균등 / **오른 우세** / … / 닫힘 / 곧음 / 직각 정도 / 붙임 / **교차·겹침** / 모음 / … |
| 오른발 돌려차기, 충격 | 서기 / **한 점** / **오른 우세** / 정립 / **옆** / **엇갈림** / 열림 / **옆굽힘** / 폄 / 벌림 / **한쪽 들림** / 옆으로 뻗음 / … |
| 오른발 돌려차기, 무릎 접음 | 서기 / 한 점 / 오른 우세 / 정립 / **사선** / 엇갈림 / 닫힘 / 곧음 / **깊이 접음** / 보통 / 한쪽 들림 / 모음 / … |

- `남녀` 값은 **예시용 평정 가정**이다. 실제 평정은 하지 않았다.
- 좌우 반전하면 위 자세 중 `좌우` 값이 있는 것(모아 앉기, 다리 꼬기, 돌려차기)만 라벨이 바뀐다.

## 5. 동작 = 자세 시퀀스

동작은 위 자세 라벨의 시퀀스다. 새 구간은 **대분류·체중 지지·다리 관계·전후 방향·다리 모양**이 바뀔 때 시작한다.
돌려차기는 `준비 서기(사선) → 한 발 들림 → 무릎 깊이 접음(엇갈림) → 다리 폄(옆, 옆굽힘) → 회수 → 착지`로 쓴다.

동작에는 자세 사이를 어떻게 가는지를 말하는 **전이 축**을 붙인다.

| 전이 축 | 질문 | 값 |
|---|---|---|
| 반복 | 같은 변화가 되풀이되나? | 한 번 · 반복 · 지속 |
| 진동 방향 | 반복된다면 어느 방향으로 흔들리나? | 없음 · 좌우 · 상하 · 앞뒤 · 회전 |
| 속도 | 얼마나 빠른가? | 느림 · 보통 · 빠름 · 폭발적 |
| 지속 | 그 상태가 얼마나 유지되나? | 순간 · 짧음 · 유지 |

돌려차기와 옆차기처럼 한 순간의 자세만으로는 구분되지 않는 동작은 `진동 방향`·`속도`에 더해 도메인 전이 축(경로 직선/호, 타격면 발바닥/발등/발날)을 추가한다.

### 손 흔들기와 윙크
| 동작 | 자세 라벨(바뀌는 축만) | 전이 |
|---|---|---|
| **손 흔들기 (오른손)** | 서기 · 팔 모양 **굽혀 올림@오른** · 손 모양 **펴짐@오른** · 입 미소 | 반복 · **좌우** 진동 · 보통 · 유지 |
| **윙크 (왼눈)** | 서기 · 눈 **한쪽 감음@왼** · 입 미소 · 머리 기울임 | 한 번 · 빠름 · **순간** |
| 오른손으로 흔들며 왼눈 윙크 | 위 두 라벨의 합 | 반복 · 좌우 · 보통 · 유지 |

- 손 흔들기는 **자세 하나 + "반복·좌우 진동"** 으로 표현한다(자세 시퀀스가 아니라 같은 자세 주변의 진동).
- 윙크는 얼굴 축 한 값이 순간적으로 바뀌는 단발 전이이다. 눈 값 `한쪽 감음`이 "어느 쪽"을 `@`로 가진다.
- VRM 아바타로 옮길 때는 윙크가 `blinkLeft`/`blinkRight` 표정(이 프로젝트의 샘플 VRM에 있는 프리셋)으로 대응된다.

## 7. 아직 하지 않은 것

- 이 축의 값들을 **실제 사람이 주석한 적이 없다.** 위 예시는 제가 작성한 것이다.
- **평정자 일치도**(같은 자세에 같은 값을 고르는가)를 측정하지 않았다. 일치도가 낮은 값은 합치거나 대표 자세를 늘려야 한다.
- 값의 경계가 애매한 축(`다리 모양`의 "약간 굽힘"과 "직각 정도", `전후 방향`의 "사선")은 대표 자세와 파일럿 주석으로 다듬어야 한다.
- 상하 반전은 일부 축만 정의되어 있고 나머지는 사람이 재해석해야 한다.
- **전이 축**의 값 정의는 이름만 있고 대표 동작이 없다. `진동`의 진폭·주기(몇 번, 얼마나 크게)도 아직 축이 없다.
- **얼굴 축은 눈·입뿐**이다. 눈썹, 뺨, 혀 등과 감정 표정(웃음·놀람 같은 묶음)은 정의하지 않았다. 몸 모션캡처 데이터에는 얼굴 정보가 없어 얼굴 라벨은 별도 데이터가 필요하다.
