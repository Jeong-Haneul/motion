# 자세 라벨 체계 v0.9 — 형상 분류(카테) + 지식 분류(명자세)

라벨은 사람이 만든다. 나는 라벨에서 자세를 만들어 VMC로 기록한다. 모든 값은 말로 된 열거형이다. 표정은 별도 체계라 여기에 넣지 않는다.
**전제: 한국어 화자의 문화적 인식 합의.** 이름을 들으면 같은 자세를 떠올린다는 합의 위에 서 있다.

- 정의: `../catalog.py`(카테1·카테2·명자세 목록), `../axes.py`(축, 추가 제어, 점검)
- 스키마: `posture_axes.schema.json`
- 점검: `python3 -m motionspec.axes`

## 1. 구조

| 층 | 무엇 | 필수 |
|---|---|---|
| **카테1 > 카테2** | **형상 분류.** 몸 전체가 어떤 모양인가 | 기본 |
| **남녀 / 노소 / 에너지** | 몸 전체에 거는 정도. 자세를 만들 때 개념대로 반영한다 | 기본 (공란은 중립) |
| 명카테1 > 명카테2 | **지식 분류.** 그 모양이 어느 분야에서 무엇이라 불리나 | 선택 |
| 추가 제어 | 부위별 값(방향·뻗음, 몸통, 머리, 손, 발끝) | 선택 |

**카테와 명자세는 서로 독립이다.** 겹쳐도 되고(만세는 카테2에도 명자세에도 있다), 대응이 1:1일 필요도 없다.
명자세의 주된 쓰임은 **보조 탐색 지표**다. 분야별로 알려진 자세를 카테2에 대조해서, 자리가 없는 자세가 있으면 카테2에 구멍이 있다는 뜻이다.

### 동작 이름은 순간을 붙인다

명자세에는 동작 이름이 많다(돌려차기, 골프 스윙, 손 흔들기). 이런 이름은 **어느 순간의 자세인지**를 괄호로 붙여 자세 하나로 고정한다.

| 순간 | 뜻 | 예 |
|---|---|---|
| 준비 | 동작을 시작하기 직전 | 골프 스윙(준비), 크라우칭 스타트(준비) |
| 중간 | 동작이 진행 중인 대표 자세 | 돌려차기(중간) = 무릎을 들어 접은 순간, 손 흔들기(중간) |
| 임팩트 | 타격·릴리스 순간, 또는 점프·동작의 정점 | 돌려차기(임팩트), 박수(임팩트), 점핑잭(임팩트) |
| 마무리 | 동작이 끝나고 멈춘 자세 | 역도(마무리) |

한 동작에 순간을 여러 개 둘 수 있고, 순간마다 다른 카테2를 가리킬 수 있다. 예를 들어 돌려차기(중간)은 `한 발 서기(무릎 올림)`, 돌려차기(임팩트)는 `한 발 서기(다리 옆으로)`다. 지금 동작 이름 343개에 순간별 자세 351개가 있다. 동작 전체는 이 순간들을 이은 자세 시퀀스로 쓴다(8절).

## 5. 추가 제어

카테2 기본 자세에서 바꿀 부위만 적는다. `팔`·`손`·`다리`·`발끝`은 양쪽, `왼팔`처럼 적으면 그쪽만.

| 부위 | 값 |
|---|---|
| 팔·다리 | **방향·뻗음**. 방향 13: 위 · 아래 · 앞 · 뒤 · 바깥 · 가로질러 · 앞위 · 앞아래 · 바깥위 · 바깥아래 · 앞바깥 · 뒤아래 · 가로아래 / 뻗음: 폄 · 굽힘 · 접음 |
| 몸통 | 곧음 · 숙임 · 젖힘 · 말림 · 옆굽힘@ · 비틂@ |
| 머리 | 앞 · 위 · 아래 · 옆@ · 갸웃@ |
| 손 | 자연 · 펴짐 · 주먹 · 가리킴 · 브이 |
| 발끝 | 앞 · 바깥 · 안쪽 |

팔·다리 값 밑에는 IK 대표값(몸 기준 방향 단위벡터 + 뻗음률 100/70/35%)이 있다.
카테2 중 49개는 기본 자세를 부위 값으로(오른쪽 기준) 적어 두었고(`BASE_PARTS`), 나머지는 이름과 남녀·노소·에너지로 개념대로 만든다.
우선순위: 기본값 < 카테2 기본 자세 < 명자세의 추가 제어 < 직접 적은 부위 값.

## 6. 좌우반전과 상하 반전

- **좌우 반전으로 같아지는 자세는 오른쪽 기준 하나만 둔다.** 카테2·명카테2에는 `@왼`·`@오른`을 적지 않는다.
- 오른쪽 기준이 무엇인지는 값마다 정해져 있다(예: 다리 꼬기 = 오른다리를 위에 얹음, 짝다리 = 오른다리에 체중, 모로 눕기 = 오른쪽이 바닥).
- 왼쪽 자세는 라벨에 **`좌우반전`**을 표시한다. 자세를 만들 때 오른쪽 기준 자세를 거울상으로 뒤집는다.
- 추가 제어의 부위 값(`왼팔`, `갸웃@왼`)은 실제 자세 그대로 적는다. 오른다리를 꼬고 왼손으로 턱을 괴는 것처럼 부위마다 쪽이 다른 자세는 여기서 표현한다.
- **좌우 반전 연산**: `좌우반전` 표시를 켜고 끄고, 부위 값의 왼·오른을 맞바꾼다. 결과는 자세의 거울상과 같다(전부 점검함).
- **상하 반전**: 카테2 쌍으로만 정의한다(바로 서기 ↔ 물구나무, 반듯이 눕기 ↔ 엎드려 눕기).
