# 자세 축 체계 v0.4 — 전체 축 + 파츠 공통 규칙 축

라벨은 사람이 만든다. 나는 라벨에서 자세를 만들고 VMC로 기록한다. 자동 라벨러는 없다. 수치 임계값도 없고, 모든 축은 말로 된 **열거형**이다.
표정은 별도 체계이며 여기에 넣지 않는다.
정의·스키마: `../axes.py`, `posture_axes.schema.json`. 점검: `python3 -m motionspec.axes`.

## 1. 구조

**명목 축 10개** = 전체 축 6 + 파츠 공통 축 4.
파츠 8개(몸통·머리·왼팔·오른팔·왼손·오른손·왼다리·오른다리)가 **같은 4개 질문**에 답하므로, 실제로 쓰는 칸은 6 + 31개다(머리는 `굽힘` 없음).
라벨에는 **기본값과 다른 칸만** 적는다. 그래서 실제 라벨은 짧다.

### 전체 축
| 축 | 값 |
|---|---|
| **대분류** | 서기 · 앉기 · 눕기 · 꿇기 · 쪼그리기 · 기대기 · 짚기 · 공중 |
| **좌우** | 대칭 · 왼 우세 · 오른 우세 |
| **상하** | 정립 · 도립 · 등 아래 · 배 아래 · 왼옆 아래 · 오른옆 아래 |
| 열림 | 닫힘 · 중립 · 열림 |
| **남녀** | 여성적 · 중립 · 남성적 (읽히는 인상, 성별 아님) |
| **노소** | 아이 · 청년 · 중년 · 노년 (읽히는 인상, 나이 아님) |

`상하`는 몸이 세상에 대해 어떻게 놓였는지를 말한다. 열거형이라 누운 방향(반듯이, 엎드림, 모로)까지 넣었다.

### 파츠 공통 축
| 축 | 질문 | 값 |
|---|---|---|
| 향함 | 뿌리에서 끝을 보면 어느 쪽? (어깨→손, 고관절→발, 골반→목, 손목→손끝; 머리는 얼굴이 보는 쪽) | 위 · 아래 · 앞 · 뒤 · 왼쪽 · 오른쪽, 반대가 아닌 것끼리 **최대 3개 조합** (`아래+앞+바깥`) |
| 굽힘 | 가운데 마디가 얼마나 접혔나? (팔꿈치·무릎·등·손가락) | 폄 · 굽힘 · 접음 (손만 `가리킴` · `기호` 추가) |
| 비틂 | 길이 방향으로 돌았나? | 없음 · 왼쪽 · 오른쪽 |
| 닿음 | 무엇에 닿았나? | 없음 · 머리 · 몸통 · 팔 · 손 · 다리 · 바닥 · 물체 · 타인 (최대 2개) |

부위마다 읽는 법이 조금 다르다.

| 부위 | 향함 | 굽힘 | 비틂 |
|---|---|---|---|
| 몸통 | 위 = 곧음, 위+앞 = 숙임, 위+뒤 = 젖힘, 위+왼쪽 = 옆굽힘 | 등이 둥글게 말림 | 가슴이 돌아간 쪽 |
| 머리 | 얼굴·시선 방향 | (없음) | 갸웃한 쪽 |
| 손 | 손끝 방향 | 폄 = 펴짐, 굽힘 = 반쯤 쥠, 접음 = 주먹 | 손바닥 돌림 |

### 쓰는 규칙
- **방향은 골반 기준**이다. 위 = 머리 쪽, 앞 = 배 쪽, 왼쪽·오른쪽 = 몸의 왼쪽·오른쪽. 몸이 세상에 놓인 방향은 `상하`만 말한다.
- **묶음 이름**: `팔`·`손`·`다리`는 양쪽에 같이 적용된다. `왼다리`처럼 한쪽을 적으면 그 칸만 덮어쓴다.
- **바깥·안쪽**: 팔·손·다리에서만 쓰는 상대 표현이다. 왼다리의 `바깥`은 `왼쪽`이다. 그래서 `다리: 아래+앞+바깥` 하나로 양다리를 벌린 모양을 쓸 수 있다. 저장은 절대값(왼쪽·오른쪽)으로 한다.

## 2. 반전

| 연산 | 바뀌는 것 |
|---|---|
| **좌우 반전** | 왼·오른 파츠가 자리를 바꾸고, 모든 `왼쪽 ↔ 오른쪽` 값과 `좌우`, `왼옆 아래 ↔ 오른옆 아래`가 바뀐다 |
| **상하 반전** | `상하`(정립 ↔ 도립, 등 아래 ↔ 배 아래, 왼옆 ↔ 오른옆)와 `대분류`(서기 ↔ 짚기)만 바뀐다. 파츠는 골반 기준이라 그대로다 |

두 번 뒤집으면 원래 라벨이고, 두 반전은 순서를 바꿔도 결과가 같다(예시 전부 점검).
만세를 상하 반전하면 `짚기 / 도립 / 팔 위·폄`, 곧 물구나무가 된다.
좌우가 `대칭`인데 파츠가 좌우로 다르면 `check()`가 경고한다.

## 3. 비어 있는 칸 채우기 (자세를 만들 때)

우선순위: **명시한 값 > 전체 느낌 축의 사전값 > 대분류 기본 모양 > 중립값**.

- **대분류 기본 모양**: 예를 들어 `앉기`는 다리 `아래+앞·굽힘·바닥`, 팔 `아래+앞·굽힘·다리에 닿음`이다.
- **사전값**(가설, 검증 안 함)

| 축 = 값 | 비어 있는 칸에 주는 값 |
|---|---|
| 열림 = 열림 | 팔·다리 향함에 `바깥`을 더함 |
| 열림 = 닫힘 | 팔은 몸통에, 다리는 다리에 닿음 |
| 남녀 = 여성적 | 다리끼리 닿음(모음), 몸통 곧음 |
| 남녀 = 남성적 | 다리 향함에 `바깥`을 더함, 앉으면 몸통 위+뒤(젖힘) |
| 노소 = 아이 | 서면 다리 향함에 `바깥`을 더함 |
| 노소 = 노년 | 몸통 위+앞·굽힘, 머리 앞+아래, 서면 무릎 굽힘 |

`앉기 + 남성적`만 적으면 `몸통 위+뒤 / 다리 아래+앞+바깥·굽힘`, 곧 다리 벌려 젖혀 앉기가 채워진다.

## 5. 표현력

| | 축 | 칸 | 비트 |
|---|---|---|---|
| 전체 축 | 6 | 6 | 12.3 |
| 파츠 공통 축 | 4 | 31 | 103.1 (부위 1개당 향함 4.7 · 굽힘 1.6 · 비틂 1.6 · 닿음 5.2) |

v0.3(10축, 23.7비트)과 명목 축 수는 같다. 하지만 파츠마다 같은 질문을 하므로 표현력이 크게 늘었다. v0.3에서 빠졌던 **손 모양, 팔 높이, 한쪽만 다른 팔·다리, 누운 방향**이 이제 들어간다.

## 6. 한계와 할 일

- **향함 조합은 방향의 정도를 말하지 않는다.** `아래+앞`은 45°일 수도, 거의 앞일 수도 있다. 필요하면 `주로 앞` 같은 값을 열거형에 더한다.
- **향함만으로 팔꿈치 위치는 정해지지 않는다.** `향함`(뿌리→끝)과 `굽힘`을 정해도 팔꿈치가 돌아가는 방향이 남는다. 지금은 `비틂`과 자연스러운 기본값으로 정한다.
- **손가락별 모양**(가리킴, 브이)은 손 `굽힘`의 예외 값으로만 있다.
- **사람이 주석한 적이 없고**, 평정자 일치도와 실제 자세 모음에서의 구별력도 재지 않았다. 사전값은 가설이다.
- 동작은 이 라벨의 시퀀스에 전이 축(반복 · 진동 방향 · 속도 · 지속)을 붙여 쓴다.
