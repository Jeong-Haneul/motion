# 자세 라벨 체계 v0.5 — 기본형 5축 + 추가 제어

라벨은 사람이 만든다. 나는 라벨에서 자세를 만들어 VMC로 기록한다. 모든 축은 말로 된 열거형이다. 표정은 별도 체계라 여기에 넣지 않는다.
정의·스키마: `../axes.py`, `posture_axes.schema.json`. 점검: `python3 -m motionspec.axes`.

## 1. 기본형 (5축)

| 축 | 값 |
|---|---|
| **카테1** | 서기 · 앉기 · 눕기 · 꿇기 · 쪼그리기 · 기대기 · 짚기 · 공중 |
| **카테2** | 카테1에 종속 (아래 표, 39개) |
| **남녀** | 여성적 · 중립 · 남성적 (읽히는 인상, 성별 아님) |
| **노소** | 아이 · 청년 · 중년 · 노년 (읽히는 인상, 나이 아님) |
| **에너지** | 처짐 · 편안 · 보통 · 힘참 · 폭발적 |

### 카테2 (`@` = 쪽을 적는 값, 괄호는 쪽의 뜻)
| 카테1 | 카테2 |
|---|---|
| 서기 | 바로 서기 · 짝다리@(체중 실은 다리) · 다리 벌려 서기 · 한 발 서기@(든 다리) · 앞서기@(앞 다리) · 기마 서기 · 겨루기 서기@(앞 다리) · 반쯤 앉은 서기 · 숙여 서기 |
| 앉기 | 바로 앉기 · 기대 앉기 · 다리 꼬기@(위 다리) · 비껴 앉기@(다리 가는 쪽) · 벌려 젖혀 앉기 · 양반다리 · 무릎 세워 앉기@(세운 무릎) · 다리 뻗고 앉기 · 무릎 껴안고 앉기 |
| 눕기 | 반듯이 · 엎드려 · 모로@(바닥 쪽) · 웅크려 모로@(바닥 쪽) · 팔베개 |
| 꿇기 | 정좌 · 무릎 서기 · 한 무릎 꿇기@(세운 무릎) |
| 쪼그리기 | 쪼그려 앉기 · 벌려 쪼그리기 |
| 기대기 | 등 기대기 · 어깨 기대기@(벽 쪽) · 팔 걸치기 |
| 짚기 | 엎드려뻗쳐 · 네발 · 옆으로 짚기@(짚은 팔) · 물구나무 |
| 공중 | 곧게 뛰기 · 벌려 뛰기 · 웅크려 뛰기 · 앞뒤 도약@(앞 다리) |

- 카테2마다 **기본 자세**가 부위 값으로 정의되어 있다(`axes.py`의 `CAT2`). 쪽이 있는 값은 `@오른` 기준으로 적고, `@왼`은 그 거울상이다(점검함).
- 몸이 세상에 놓인 방향(정립 · 도립 · 등/배/옆 아래)은 카테2가 정한다. 예: `물구나무` → 도립, `모로@오른` → 오른옆 아래.
- 차렷과 편히 서기는 같은 `바로 서기`이고 **에너지**(힘참 / 편안)로 가른다.

### 남녀 · 노소 · 에너지 = 몸 전체에 거는 "정도"
부위 라벨에는 정도가 없다. 정도는 이 세 축이 자세를 만들 때 몸 전체에 건다.

| 축 | 몸에 거는 것 |
|---|---|
| 남녀 | 열림–닫힘(무릎·팔 모음/벌림), 골반 쓰임(여성적) vs 어깨 쓰임(남성적) |
| 노소 | 척추 굽음, 무릎 굽힘, 몸통 숙임, 보폭 |
| 에너지 | 뻗음률(처짐은 덜, 폭발적은 끝까지), 척추 펴짐, 자세 폭, 동작이면 속도 |

이 효과를 정확히 얼마나 거는지는 아직 정하지 않았다(아래 4절).

기본형만으로 만들 수 있는 조합: (카테2 39 + 쪽 있는 것 13) × 3 × 4 × 5 = **3,120**.

## 2. 추가 제어 (필요할 때만)

기본 자세에서 바꿀 부위만 적는다. `팔`·`손`·`다리`는 양쪽, `왼팔`처럼 적으면 그쪽만 바꾼다.

| 부위 | 값 |
|---|---|
| 팔·다리 | **방향·뻗음**. 방향 12: 위 · 아래 · 앞 · 뒤 · 바깥 · 가로질러 · 앞위 · 앞아래 · 바깥위 · 바깥아래 · 앞바깥 · 뒤아래 / 뻗음 3: 폄 · 굽힘 · 접음 |
| 몸통 | 곧음 · 숙임 · 젖힘 · 말림 · 옆굽힘@ · 비틂@ |
| 머리 | 앞 · 위 · 아래 · 옆@ · 갸웃@ |
| 손 | 자연 · 펴짐 · 주먹 · 가리킴 · 브이 |

팔·다리 값 밑에는 **IK 대표값**이 있다.
- 방향은 몸 기준 단위벡터(어깨→손, 고관절→발)다.
- 뻗음률은 끝까지 거리를 팔(다리) 길이로 나눈 값이다(폄 100%, 굽힘 70%, 접음 35%).
- 예: `오른팔 바깥위·접음` → 방향 (0.71, 0.71, 0), 뻗음 35%.

## 3. 반전

- **좌우 반전**: 카테2의 `@왼 ↔ @오른`, 왼·오른 부위, 몸통·머리의 `@` 값을 맞바꾼다. 라벨을 뒤집은 결과는 자세의 거울상과 같다(점검함).
- **상하 반전**: 카테2 쌍으로만 정의한다. `바로 서기 ↔ 물구나무`, `반듯이 ↔ 엎드려`. 그 밖의 값은 다시 라벨링한다.

## 5. 한계와 할 일

- **남녀·노소·에너지의 효과가 아직 수식이 아니다.** 지금은 효과의 종류만 적혀 있어서, 차렷·편히 서기·노인 서기가 부위 값으로는 같다. 자세를 만들 때 이 효과를 IK 대표값에 거는 규칙을 정해야 한다.
- 카테2 기본 자세와 IK 대표값은 내가 정한 값이고 아직 그려 보지 않았다.
- 팔꿈치·무릎이 향하는 쪽(스위블)과 손·발 회전은 추가 제어에 없다.
- 상하 반전은 두 쌍만 정의했고, 추가 제어 값은 반전 뒤 그대로 따라가서 어색할 수 있다(예: 손 흔들기를 상하 반전한 물구나무).
- 사람이 주석한 적이 없고 평정자 일치도도 재지 않았다.
- 동작은 이 라벨의 시퀀스에 전이 축(반복 · 진동 방향 · 속도 · 지속)을 붙인다.
